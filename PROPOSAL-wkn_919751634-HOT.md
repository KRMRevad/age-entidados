## 📋 Escopo do Projeto

Buscamos um desenvolvedor freelancer experiente para realizar a integração do sistema Drive Parts com o DETRAN do Rio Grande do Sul. O objetivo principal é automatizar consultas e o envio de dados obrigatórios para desmontes automotivos credenciados, garantindo conformidade e eficiência operacional. 
Sobre o Sistema Drive Parts:
Somos uma plataforma SaaS robusta, projetada especificamente para desmontes automotivos. Nossas funcionalidades incluem:
- Gerenciamento de estoque de peças com compatibilidade veicular.
- Publicação automática de peças em nosso site próprio, Mercado Livre e Mercado Drive.
- Operação em ambiente multi-tenant.
- Tecnologia baseada em PHP 8.2, Symfony 7.4 e MongoDB.
- Infraestrutura rodando em Linux (VPS). 
Escopo do Projeto:
O projeto envolve as seguintes etapas e responsabilidades:
- Estudo aprofundado da documentação técnica fornecida pelo detran rs.
- Implementação da integração via api rest ou soap, conforme as especificações do detran.
- Tratamento de autenticação, que pode envolver o uso de tokens ou certificados digitais, se necessário.
- Criação de um serviço desacoplado dentro do framework Symfony para gerenciar a integração.
- Implementação robusta de tratamento de erros e sistema de logs para monitoramento.
- Elaboração de documentação técnica completa da integração realizada. 
Funcionalidades Esperadas:
O sistema integrado deverá ser capaz de:
- Realizar consultas de veículos utilizando placa ou chassi.
- Validar a situação cadastral dos veículos.
- Enviar dados obrigatórios do desmonte ao DETRAN (se aplicável).
- Registrar e logar todas as requisições e respostas da API. 
Requisitos Essenciais:
- Experiência comprovada com PHP 8+ e framework Symfony.
- Habilidade em integração com Apis rest e/ou soap.
- Conhecimento e experiência com certificado digital é um diferencial.
- Experiência prévia com APIs governamentais será valorizada.
- Proficiência no uso de Git para controle de versão e adesão a boas práticas de código.
